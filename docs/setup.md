# Setup

Get the panel built, configured and flashed. Back to the [README](../README.md).

## Repository layout

```
crows-nest-eink/
├── crows-nest-eink.ino      main sketch: UI, HA client, buttons, refresh policy, sleep
├── gfx.h                    bounds-checked drawing, dithering, text (Elecrow + GFX fonts)
├── icons.h                  dithered weather icons, light bulb, status dot
├── gfxfont_types.h          Adafruit GFX font structs (so no Adafruit library is needed)
├── FreeSans*.h              bundled fonts (9pt, Bold 9/12/24pt)
├── EPD*.h / EPD*.cpp        Elecrow e-paper driver and bitmap fonts
├── secrets.example.h        template for secrets.h (WiFi, HA URL and token, static IP)
├── secrets.h                your credentials (gitignored)
├── config.example.h         template for config.h: entity IDs, light tiles, units, mining
├── config.h                 your entity map (gitignored; the example is used if it's missing)
├── easter_eggs_example.h    sample Easter egg photos, used when easter_eggs.h is missing
├── easter_eggs.h            your photos, generated by Image2Eink (gitignored, optional)
├── Image2Eink/              browser tool that makes easter_eggs.h (see its README)
└── docs/                    setup, Home Assistant guide, screens, customising, troubleshooting
```

## 1. Arduino IDE

Install the **ESP32 board package** (Espressif). Development used core 3.x; Elecrow's tutorial specifies 2.0.14.

| Setting | Value |
|---|---|
| Board | ESP32S3 Dev Module |
| **USB CDC On Boot** | **Disabled** (otherwise the serial monitor stays silent) |
| CPU Frequency | 240 MHz (WiFi) |
| Flash Mode | QIO 80 MHz |
| Flash Size | 8 MB (64 Mb) |
| Partition Scheme | Huge APP (3 MB No OTA / 1 MB SPIFFS) |
| PSRAM | OPI PSRAM |
| Upload Mode | UART0 / Hardware CDC |
| Upload Speed | 921600 |
| Serial monitor | 115200 baud |

**Libraries:** only **Arduino_JSON** (by Arduino, 0.2.x) from the Library Manager. WiFi and HTTPClient come with
the ESP32 core. The Elecrow driver and fonts are already in the sketch folder.

Uploads work even while the panel is light-sleeping, because the USB-to-serial bridge stays powered and resets the
chip. If an upload ever hangs at "Connecting…", hold BOOT, tap RESET, release BOOT and upload again.

## 2. Home Assistant token

Create a long-lived access token (your profile ▸ **Security** ▸ **Long-lived access tokens**). The sketch renders one
template through `POST /api/template`, which may need an admin user's token. The
[Home Assistant setup guide](home_assistant_setup/home-assistant-setup.md#0-before-you-start) has the details.

## 3. Secrets

Copy `secrets.example.h` to `secrets.h` and fill it in:

```cpp
#define WIFI_SSID      "your-wifi-name"
#define WIFI_PASSWORD  "your-wifi-password"
#define HA_BASE_URL    "http://192.168.1.50"      // include :8123 if HA uses the default port
#define HA_TOKEN       "eyJhbGciOi..."

#define USE_STATIC_IP  1                           // 0 = DHCP
#define PANEL_IP       192, 168, 1, 60
#define PANEL_GATEWAY  192, 168, 1, 1
#define PANEL_SUBNET   255, 255, 255, 0
#define PANEL_DNS      192, 168, 1, 1
```

`secrets.h` is gitignored. Pick a static IP outside your router's DHCP range, or reserve it on the router.

## 4. Entity map

Copy `config.example.h` to `config.h` and point it at your own entities. Every line is commented, and the
[Home Assistant setup guide](home_assistant_setup/home-assistant-setup.md) shows how to create each entity, plus a
[config mapping table](home_assistant_setup/home-assistant-setup.md#7-panel-config-mapping).

## 5. Flash

Open `crows-nest-eink.ino`, compile and upload. Arduino needs the sketch folder to have the same name as the
`.ino` file, so keep the folder called `crows-nest-eink`. On boot the panel shows "Connecting to Home Assistant"
and a status line, then the dashboard.

**The serial monitor logs:**
- the full template sent to Home Assistant (printed once at boot)
- each request with its response code and timing
- each refresh with its reason and timing, plus refresh counts:
  ```
  Refreshes: session 3 full + 41 partial, lifetime 57 full + 1290 partial
  ```
  Lifetime counts are saved in the ESP32's NVS flash, so they survive reboots and re-flashing. They only reset
  if you erase the whole flash.
- each sleep and wake
